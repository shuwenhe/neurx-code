📋 必需配置项（缺一不可）:

┌────────────────────────────────────────────────────────────┐
│ 1️⃣  工作空间路径 (Workspace Path)                          │
└────────────────────────────────────────────────────────────┘

  在哪里设置：
  • 方式1: File → Open Workspace → 选择目录
  • 方式2: File → Open Folder → 选择目录
  • 方式3: 直接拖拽文件夹到窗口

  正确配置：
  ✅ 路径应为: /Users/feifei/agent/neurx-code
  ✅ 窗口标题显示该路径（不是"No workspace"）
  ✅ 文件浏览器面板显示src/目录结构

  验证方法：
  → 查看窗口标题栏
  → 查看左侧文件浏览器是否显示项目文件

┌────────────────────────────────────────────────────────────┐
│ 2️⃣  自动批准工具 (Auto-approve Tools)                      │
└────────────────────────────────────────────────────────────┘

  在哪里设置：
  • 点击右上角 ⚙️ Settings 图标
  • 滚动到 "Safety" 或 "安全" 部分
  • 找到 "Auto-approve safe tools" 开关

  正确配置：
  ✅ 开关状态: ON（已打开）
  ✅ 颜色通常为蓝色/绿色（表示启用）

  重要说明：
  ⚠️  如果不启用此项，agent每次调用工具都需要手动批准
  ⚠️  批准提示可能不明显，导致看起来像"没反应"

┌────────────────────────────────────────────────────────────┐
│ 3️⃣  LLM Provider配置                                        │
└────────────────────────────────────────────────────────────┘

  选项A - OpenAI (SiliconFlow):
  ✅ Provider: OpenAI
  ✅ API Key: 已填写（从SiliconFlow获取）
  ✅ Endpoint: https://api.siliconflow.cn/v1/chat/completions
  ✅ Model: Qwen/Qwen3-32B

  选项B - Ollama (本地):
  ✅ Provider: Ollama
  ✅ Endpoint: http://localhost:11434
  ✅ Model: qwen3:8b 或 qwen2:0.5b
  ✅ Ollama服务正在运行（终端测试: ollama list）

🧪 测试步骤:

  1. 确认上述3项配置都正确
  
  2. 在neurx-code聊天框输入:
     "你好，请自我介绍"

     → Agent应该生成代码并自动创建文件
     → 如果只显示代码没创建文件 → workspace/auto-approve有问题
  
  4. 验证文件已创建:
     终端运行: ls -lh /Users/feifei/agent/neurx-code/src/hello_agent.cc

🔍 常见问题:

  Q: 窗口标题显示路径，但文件还是没创建？
  A: 检查auto-approve是否真的启用了（开关是ON状态）

  Q: Auto-approve已启用，但还是要手动批准？
  A: 重启neurx-code，让设置生效

  Q: Agent说"我不能创建文件"？
  A: 这是LLM的误解，不是代码问题。换个说法：
     "使用agent_file_writer工具创建src/test.cc文件"

  Q: 找不到Settings中的Safety部分？
  A: 不同版本UI可能不同，找类似名称：
     • Security / 安全
     • Tools / 工具
     • Permissions / 权限
